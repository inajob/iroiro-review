はんだスプールをおもりにした基板固定ツール
3Dプリンタ
Published: 2026-09-08

Compact PCB Vise Uses Up That Leftover Filamentから発見。画像もここから転載。

3Dプリントで基板固定台の作例は様々ありますが、自重が軽く、基板にはんだ付けの熱やテンションを加えた際に作業台の上で動いてしまいやすい課題があります。

この記事では、70g未満のフィラメントで出力できるコンパクトなPCBバイスでありながら、はんだリール自体をカウンターウェイトとしてセットすることで安定性を補う設計が紹介されています。

身近な消耗品を作業台の重しとして機構の一部に組み込む発想が合理的で面白いです。
