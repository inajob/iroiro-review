3Dプリンタで作った対戦型ピンボールマシン
3Dプリンタ おもちゃ
Published: 2026-05-18

Can You 3D Print A Pinball Machine That’s Fun To Play?から発見。画像もここから転載。

3Dプリンタで作った対戦型ピンボールマシンの作例です。 この作例自体はkickstarterのキャンペーンであり、モデルデータは有料ですが、似たような作例はいくつもあります。

本物のピンボールマシンと比べるとどうしても迫力に欠けてしまいますが、鉄球× 3Dプリンタ というのはいろいろなおもちゃを作る題材として面白そうです。

そういえば「バトルドーム 」なんておもちゃもありましたね。（最近復刻したらしいです）
